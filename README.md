# Scarlab Icons — Figma Plugin

A [Figma plugin](https://www.figma.com/community/plugin/1053846082213772972/Scarlab-Icons) for inserting [Scarlab Icons](http://scarlab-icons.la-moore.ru/) into your designs. Search 2800+ icons in four styles — Base, Outline, Solid and Ghost — and click an icon to add it to the canvas as an editable vector.

## Development

```shell
npm install
npm run build
```

In Figma desktop, go to **Plugins → Development → Import plugin from manifest…** and select `dist/manifest.json`.
